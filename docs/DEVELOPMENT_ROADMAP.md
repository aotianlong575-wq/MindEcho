## Phase 3: AI 引擎 (预计 3-4 周)

```
目标：实现遗忘预测和智能复习
```

### 3.1 遗忘预测引擎（模块五）
- [ ] 艾宾浩斯遗忘曲线基础模型

- [ ] 掌握度实时计算

### 3.2 智能复习系统（模块六）

- [ ] AI 随机出题（基于知识点内容）

### CoreML 模型列表
| 模型 | 输入 | 输出 | 用途 |
|------|------|------|------|
| ForgettingPredictor.mlmodel | 复习次数/难度/间隔/正确率 | 遗忘概率 | 遗忘预测 |
| DifficultyClassifier.mlmodel | 文本特征向量 | 难度等级 | 自动定级 |
| QuestionGenerator.mlmodel | 知识点内容 | 题目候选 | AI 出题 |

## 技术难点与风险

| 难点 | 风险等级 | 应对策略 |
|------|----------|----------|
| CoreML 遗忘预测精度 | 🔴 高 | 先使用艾宾浩斯公式，ML 作为增强 |
| visionOS 3D 性能 | 🟡 中 | 限制同时渲染节点数 < 200 |
| OCR 中英文混合识别 | 🟡 中 | 使用 Vision VNRecognizeTextRequest 自适应 |
| 知识图谱大数据量 | 🟡 中 | 分页加载 + 虚拟化渲染 |
| iCloud 同步冲突 | 🟢 低 | SwiftData 自动处理 |
